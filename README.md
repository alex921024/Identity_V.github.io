# 約你打第五

這個專案是一個以手機介面為主的互動式告白頁面，主要內容是一個「邀請對方一起打第五」的流程頁面，包含首頁、確認頁、時間選擇、模式選擇與結果回覆。

## 專案檔案

- original.html：原始版本，所有 HTML、CSS、JS 併在同一個檔案中。
- index.html：目前的頁面結構檔案，負責網頁內容與視圖組成。
- Identity V.css：目前的樣式檔案，包含主題色、布局、卡片、動畫與響應式調整。
- Identity V.js：目前的互動邏輯檔案，包含切換頁面、按鈕互動、時間選擇、結果生成等功能。

## 原檔與修改版本說明

### 1. original.html

original.html 是此專案的原始版本，特點是：

- HTML、CSS 與 JavaScript 全部集中在同一個檔案內
- 所有頁面樣式直接寫在 style 區塊中
- 互動邏輯也直接嵌入網頁內文
- 適合作為基礎版本或原始草稿使用

### 2. index.html

Identity V.html 是後續整理後的版本，差異如下：

- 把原本大段內嵌的 CSS 抽離出來，改由 Identity V.css 載入
- 保留主體 HTML 結構與內容，但讓檔案更容易維護
- 更適合做版型整理與後續功能擴充

### 3. Identity V.css

Identity V.css 是從 original.html 中抽離的樣式檔，主要差異如下：

- 將原本的內嵌 style 區塊拆分為獨立 CSS 檔
- 重新整理版面結構與動畫效果
- 強化手機版視覺表現與互動感
- 讓色彩、按鈕、卡片、圓角等設計更集中管理

### 4. Identity V.js

Identity V.js 是從原始頁面中拆離的互動腳本，主要新增與優化項目：

- 視圖切換：首頁、確認頁、時間頁、模式頁、結果頁
- 「不要」按鈕逃跑效果
- 模擬系統狀態欄時間更新
- 日期與時間的選擇邏輯
- 模式多選功能
- 結果頁資料填充與回覆生成
- 複製結果圖片與儲存圖片功能

## 主要差異總結

與 original.html 相比，目前版本的主要改動是：

- 將單一檔案拆成結構、樣式、邏輯三個檔案
- 把內嵌 CSS 抽離成 Identity V.css
- 把腳本邏輯抽離成 Identity V.js
- 提升程式可讀性與後續維護性
- 新增更完整的使用者互動流程
- 補強時間與模式選擇的功能性與畫面流程

## 使用方式

1. 直接開啟 index.html 即可瀏覽頁面。
2. 如果需要修改樣式，請編輯 Identity V.css。
3. 如果需要調整互動邏輯，請編輯 Identity V.js。
4. original.html 可作為原始版本保留，方便比較修改差異。
